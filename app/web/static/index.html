Quick Controls & Status

Friday STT runs in your Windows System Tray (near your clock). You can dictate directly into any active application without opening any browser or window.

Push-to-Talk Hotkey
Ctrl + Space
Hold to speak, release to paste
Hands-Free Toggle Hotkey
Ctrl + Shift + Space
Press once to record, press again to stop
Clipboard Safe Mode
Active (Guaranteed)
Transcripts stay in clipboard so you never lose speech
Microphone Privacy
On-Demand (~19ms)
Mic is 100% closed when idle (Taskbar icon OFF)
💡 How to launch desktop assistant: Double-click run.bat in the project folder to start the background tray assistant.
